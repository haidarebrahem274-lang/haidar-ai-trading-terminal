# haidar-ai-trading-terminal
منصة تداول ذكية باسم HAIDAR AI TRADING TERMINAL، توفر متابعة الأسواق المالية وتحليل البيانات الفنية وإشارات التداول التجريبية للذهب والفوركس والعملات الرقمية والأسهم والمؤشرات والطاقة، مع الرسوم البيانية والمؤشرات الفنية وإدارة المخاطر وسجل الإشارات. واجهة عربية احترافية متوافقة مع الهواتف وقابلة للتثبيت كتطبيق ويب (PWA).
