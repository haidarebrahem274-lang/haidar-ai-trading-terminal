# HAIDAR AI TRADING TERMINAL

منصة عربية متوافقة مع الهواتف لعرض بيانات السوق وتحليلها فنياً.

## الملفات
- `index.html`: واجهة المنصة.
- `manifest.json`: إعدادات التطبيق القابل للتثبيت.
- `sw.js`: التخزين المؤقت للواجهة.

## مصدر البيانات
تطلب الواجهة بيانات الشموع من Supabase Edge Function:
`https://czezgeslfxhpbrtquffy.supabase.co/functions/v1/market-data-proxy`

الأسواق والأطر المتاحة فعلياً تعتمد على إعدادات Edge Function ومزود البيانات. الواجهة تستخدم الشموع المغلقة فقط، وتستبعد الشمعة الحالية غير المكتملة والتوقيتات المفقودة والمكررة. عند نقص البيانات أو قدمها تعرض حالة انتظار ولا تختلق أسعاراً أو شموعاً. قائمة الرموز مبنية على قائمة المزود العامة، لكن إتاحة كل رمز/فريم تعتمد على الخطة.

## شروط الإشارة
- الحد الأدنى 60 شمعة مغلقة.
- تُرفض البيانات إذا كان آخر إغلاق أقدم من 3 فترات زمنية أو توقيته غير منطقي.
- الإشارة تتطلب اكتمال المؤشرات، توافق اتجاه EMA، ودرجة اتجاهية قوية دون تعارض كبير مع نقاط الاتجاه المقابل، وADX لا يقل عن 20.
- لا يتم تجميع M15/H4 إلا من مجموعات شموع أساس مكتملة؛ D1 لا يُشتق من H1.

## تنبيه
الإشارات تعليمية وليست نصيحة استثمارية. لا يوجد تنفيذ تلقائي للصفقات أو اتصال بحساب MT5.
